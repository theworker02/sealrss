# sealrss

Seal validation gates for rss inputs before they hit prod.

**Site:** https://theworker02.github.io/sealrss/

## Install / run

```bash
git clone https://github.com/theworker02/sealrss.git
cd sealrss
node src/cli.js
node --test
```
